Reset Command

Local/dev only: from backend/, run venv\Scripts\python.exe manage.py reset_demo_data. The command deletes reseedable tutee/tutor demo data, preserves Admin and SuperAdmin logins, and recreates the named scenarios with the shared password above. It also reseeds all InstitutionCourseCatalog entries for CPU and North University so subject visibility works correctly in every demo flow.

Catalog-only update — if you only need to populate the InstitutionCourseCatalog without wiping tutee/tutor accounts, run venv\Scripts\python.exe manage.py populate_course_catalog instead. This matches each subject's category field to the corresponding course code and creates catalog entries for every institution. Requires subjects to already have category set (i.e. reset_demo_data must have been run at least once, since seed_data does not set category).

Source of truth: demo data testing guide and backend/studybuddy/management/commands/reset_demo_data.py.
