Algorithm Demo Testing Guide

How to enable, log into, and exercise the SuperAdmin Algorithm Demo page — the tool that runs the real hybrid recommender (CBF + CF) against seeded data, and shows the tutees and tutors whose scenarios prove each part of the scoring.

Shared password studybuddy123

Where

SuperAdmin panel → /superadmin/algorithm-demo. Ranked List and Compare Pair tabs.

Gate

IsAuthenticated + IsSuperAdminUser, plus the ALGORITHM_DEMO_TOOLS_ENABLED flag — checked first, 403 when off.

Data

Runs the real hybrid.py recommender against whatever is currently seeded — not a mock or a fixture.

Scope

Unscoped by institution by default (any subject-matching tutor). An optional institution filter narrows it.

Enabling the tool

The flag defaults to OFF everywhere. It must be explicitly turned on per environment.

Local dev

  1. In backend/.env, set ALGORITHM_DEMO_TOOLS_ENABLED=true.
  2. Restart the Django server so the setting reloads: cd backend && venv\Scripts\python.exe manage.py runserver.
  3. Log in as a SuperAdmin (superadmin@studybuddy.test, password studybuddy123) and open /superadmin/algorithm-demo.

Demo deployment (Render)

Render env vars are not read from any .env file — they live in the Render dashboard only. If the page shows "Algorithm demo tools are disabled on this backend," the var was never added there.

  1. Render dashboard → studybuddy-demo-backend service → Environment tab.
  2. Add ALGORITHM_DEMO_TOOLS_ENABLED = true.
  3. Save — Render auto-redeploys on env var changes.
  4. Once redeployed, log in on the demo frontend as a promoted SuperAdmin and revisit the page.

Per the demo deployment plan, this flag should stay ON for the protected demo environment (defense/testing) and OFF for any future real production deployment.

Before you start: reset the demo data

From backend/, run venv\Scripts\python.exe manage.py reset_demo_data. Local/dev only, destructive: wipes all Tutee/Tutor users and reseeds the named personas below with a fixed random seed (same result every run). Admin and SuperAdmin logins are never touched.

How the CF signal was built

Ramon Aquino and Cecilia Mercado are rated by every cluster member with inverted patterns: Cluster A rates Ramon high / Cecilia low; Cluster B rates the opposite. Pearson similarity needs at least 2 shared, non-identical ratings to compute — the two anchors provide exactly that, and the inversion is what separates the clusters and lets Diane Cruz's neighborhood outvote raw CBF.

Walkthrough

Ranked List tab

  1. Pick a tutee (e.g. Bea Santos) from the searchable dropdown.
  2. See every subject-matching tutor ranked by Hybrid Score.
  3. Click any row to animate its CBF/CF breakdown.

Compare Pair tab

  1. Pick a tutee, then a tutor (e.g. Diane Cruz → Miguel Torres, then Diane Cruz → Elena Bautista).
  2. See stat cards for both sides: subject preferences/expertise and tutor rating history.
  3. Watch the same animated CBF/CF/Hybrid breakdown, side by side.

Live rating edit (added 2026-07-08)

In Compare Pair, each contributing Top-K Neighbor row has an editable rating input (1–5) and a Save button — no Django admin tab needed.

  1. Select Diane Cruz → Elena Bautista.
  2. Lower one neighbor's rating and click Save.
  3. The CF bar, CF score, and Hybrid Score re-animate live — no page reload — and the tutor picker's score label updates too.
  4. Switch to Miguel Torres for the same tutee: his breakdown is untouched, proving the edit is scoped to the exact (tutee, tutor) pair, not a page-wide refresh.

Gated by the same ALGORITHM_DEMO_TOOLS_ENABLED flag as the rest of the page. See the live rating edit design doc.

Things to know

  • The candidate pool is unscoped by institution by default — any subject-matching tutor, any institution. An institution filter (defaulting to "All institutions") narrows both the tutee picker and the tutor candidate pool.
  • Changing the institution filter while a tutee is selected clears that selection, since it may no longer be valid under the new scope.
  • CS-211/CS-212 are reserved to Miguel and Elena (no filler tutor teaches them) so these scenarios stay top-ranked.
  • ~30 tutors (15% of the pool) deliberately have zero sessions and zero ratings, matching Nico Villareal's empty-state case — not missing data.
