Implementation notes carried by this mockup

  • Ranked-list scores move from toFixed(2) to toFixed(3) so an on-screen tie is a real tie.
  • The Tie Breaker badge appears only on rows belonging to a tie group of 2 or more.
  • The Tie Breaker block renders only when the selected tutor is in a tie group; it is absent otherwise.
  • Badge styling reuses the existing .sb-badge pattern with a warning-tone variant, alongside the existing Cold Start badge.
