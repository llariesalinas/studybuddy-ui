Algorithm Settings — chosen design

Decision artifact for docs/plans/2026-08-19-dynamic-algorithm-weights.md. Addresses the thesis panel comment that an admin should be able to edit each part of the recommendation algorithm. Interactive: drag any slider and the preview re-sorts.

  • Scope — the two weight groups only: hybrid blend (2) and CBF components (6).
  • Storage — one row per weight keyed by group + key, with updated_by / updated_at.
  • Constraint — raw values stored, normalised at score time, so no invalid set exists.
  • Control — sliders at 5% steps; displayed percentage is the derived share.
  • Preview — searchable tutee picker, gated behind ALGORITHM_DEMO_TOOLS_ENABLED; controls stay available when it is off.
  • Save — single action, no confirmation; the preview is the confirmation.
