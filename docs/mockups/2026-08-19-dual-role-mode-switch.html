The mode switcher is now for deliberate switching only. Deep links handle themselves.

Why this generalises beyond check-in

The same bounce happens anywhere a link crosses modes. Check-in is just the one with a price tag.

Bounces today (all silent)

  • Session check-in → ₱50 strike
  • "Jomar sent you a message" → tutor chat room
  • "Your payout was released" → tutor wallet
  • "Your documents expire in 7 days" → tutor renewal
  • "New booking confirmed" → tutor schedule

What auto-switch does not change

  • can_tutor = false still bounces — that's where your "You don't have a Tutor account" modal fires
  • SuperAdmin never switches
  • Backend stays authoritative; mode is never a permission
  • Deliberate switching still lives in the sidebar
