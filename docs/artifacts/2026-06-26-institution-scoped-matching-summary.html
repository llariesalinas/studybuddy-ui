Implementation Summary

Institution-Scoped Tutor Matching

Tutees are now hard-filtered to see only tutors from their own institution across all recommendation and search surfaces. Cross-institution leakage is impossible.

Date: 2026-06-26 Branch: feature-sidebar-redesign Stack: Django 6.0 · Django REST Framework · PostgreSQL Tests added: 9
Goal A CPU tutee (cpu.edu.ph) must never see tutors from a different institution, and vice versa. The filter is a hard exclusion — no cross-institution leakage, no soft preference fallback.
