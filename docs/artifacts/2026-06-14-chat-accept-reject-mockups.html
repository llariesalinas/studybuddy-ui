Accept / Reject pending sessions in chat

Three ways to let a tutor accept or reject a pending session straight from the chat banner — alongside the existing edit-final-location control. Toggle the role and session type to see how each design adapts. The buttons are clickable.

Tutees never see Accept/Reject — only the tutor decides. F2F shows the location control; online does not.

Option A

Inline actions

Smallest change. Keeps today's banner and just adds Accept + Reject pills to the action area, next to the location control.
